# Experimental Results

This directory contains the evaluation outputs of the quantum readout-error prediction experiments.

## Files

- `validation_comparison.csv` — Validation performance comparison across the evaluated regression models.
- `figures/` — Visualisations generated during model evaluation.

## Evaluation Metrics

- **MAE:** Mean Absolute Error
- **RMSE:** Root Mean Squared Error
- **R²:** Coefficient of Determination

The results should be interpreted in the context of the dataset version, feature engineering procedure, and chronological validation split used in the experiment.
